소자 연구 문헌을 서지 정보·연구 질문·방법론·원문 근거로 탐색하는 개인 논문 라이브러리입니다.
공개 맵에는 기존 32편, 추가 수집 문헌 156편과 새로 찾은 문헌 12편을 합한 200편, 46개 개념, 116개 근거 연결과 41개 논문 쌍에 대한 32개의 연구 질문을 수록합니다. 추가 156편 중 13편은 원문 검토(2쪽 학회 요약 1편 포함)를 마쳤으며, 나머지 143편은 서지·주제 분류만 등록되어 있습니다.
개인 맵에는 DOI·PDF로 논문을 추가할 수 있습니다.

## 단계별 연구 맵

처음에는 7개 큰 연구 주제만 표시합니다. 주제 점을 누르면 바로 아래 하위 주제만 펼쳐지고, 마지막 주제 또는 ‘이 주제의 모든 논문’을 누르면 논문 군집으로 들어갑니다. 위 경로와 ‘상위 주제’ 버튼으로 돌아갈 수 있습니다. 초기 화면에는 교차 연결선을 그리지 않으며, 논문 단계에서는 선택한 논문의 선만 표시합니다.

문헌이 많은 주제는 한 화면에 최대 48편씩 표시하고 이전·다음 묶음으로 이동합니다. 상위 주제의 전체 편수와 현재 표시 편수를 구분합니다.

## 논문 추가와 개인 맵

1. **논문 추가**에서 DOI 또는 doi.org 링크를 입력하면 Crossref에서 제목·저자·게재처·연도와 제공되는 초록을 가져옵니다. Crossref 미등록 DOI나 조회 오류는 직접 입력으로 처리할 수 있습니다.
2. **PDF 파일 선택**은 브라우저 안에서 텍스트를 읽습니다. 첫 페이지의 DOI 후보를 확인한 뒤 서지 조회를 할 수 있습니다. PDF는 25 MB, 텍스트 추출은 처음 40쪽까지 지원합니다. 암호화·스캔 PDF는 잠금 해제 또는 별도의 OCR/직접 입력이 필요합니다.
3. 소자·공통 방법론 태그를 검토하고 **개인 맵에 추가하고 위치 보기**를 누릅니다. 같은 DOI는 중복 추가하지 않습니다. 임의의 추가 논문을 저자의 연구로 간주하지 않으며, 해당하는 경우에만 ‘내가 저자인 연구’를 선택합니다.
4. **내 라이브러리**에서 분류·메모를 수정하고 JSON을 내보내거나 가져옵니다. 개인 항목은 해당 브라우저의 localStorage에만 저장되므로 다른 기기나 사이트 주소로 자동 동기화되지 않습니다. 브라우저 데이터 삭제 전 JSON으로 백업하세요.

PDF 파일·추출 전문은 저장·전송하지 않습니다. 서지 조회 버튼을 누를 때 DOI만 Crossref에 전달합니다. 개인 JSON에는 서지·초록·분류·메모가 포함되며, 공개 반영은 원문 근거를 검토한 후 별도로 진행합니다.

자동 배치는 제목·초록·추출된 본문의 키워드와 사용자가 선택한 태그를 사용합니다. 임베딩/KNN 또는 LLM의 원문 심사 결과가 아닙니다. 자동 연결은 ‘연결 후보 · ?’로 표시하고 검증된 인용·상충과 구별합니다.

원문 검토가 포함된 개인 JSON을 가져오면 **원문 검토** 버튼에서 확인한 문헌, 참고문헌 인용, 접근·조건 비교와 후속 질문을 볼 수 있습니다. 인용선은 출발 논문의 참고문헌 위치를, 비교선과 질문은 양쪽 원문 근거를 요구합니다. 검토된 개인 논문의 자동 태그 연결은 끄고 근거 연결만 표시합니다. 별도로 공개한 검토는 모든 브라우저에서 보이며, 나머지 개인 검토 기록은 이 브라우저와 JSON 백업에만 저장합니다. 서지 보정 후에도 논문 ID를 유지하며, 검토 업데이트는 기존 연구자 표시와 개인 메모를 보존합니다.

개인 맵은 최대 3,000개의 서지 항목과 8 MB 이하 JSON 가져오기를 지원합니다. 실제 저장 가능량은 브라우저 저장 공간에 따라 달라집니다. 저장 공간이 부족하면 가져오기를 중단하고 기존 데이터를 유지합니다. 대량 후보의 기본 연결은 검토된 공개 문헌을 대상으로 계산하며, 개인 논문의 위치 보기에서는 다른 개인 논문도 방법론 이웃으로 조회합니다.

대용량 PDF/ZIP 일괄 정리는 로컬 폴더에서 별도로 선별한 뒤 개인 맵 JSON으로 가져오는 방식입니다. 웹사이트의 파일 선택은 단일 PDF용이며 ZIP을 직접 처리하지 않습니다. 원본 PDF, 압축 파일, 로컬 경로, 추출 전문은 공개 사이트 소스에 포함하지 않습니다. 자동 선별 기록과 원문 근거를 확인한 관계를 구별해야 합니다.

## 쟁점·미싱 링크

**쟁점 · 미싱 링크**는 이미 수록된 논문 사이의 조건 차이와 추가 검증을 비교합니다. Retention(패턴 경계·온도 이력·trap과 배열 tail), 동작 및 물리 모델(에너지 완화·ISPP 영역과 파형), 생성형 AI·전이학습·일반화 질문을 포함합니다. 각 질문에는 비교할 논문 쌍, 양쪽 주장·원문 위치·확인 범위·검증할 실험이 있습니다. 논문 쌍을 선택하면 두 논문과 물음표만 확대되며, 기존에 확인된 인용·비교 관계도 함께 표시합니다.

기본 연결선 범위는 **선택한 논문만**입니다. 전체 관계는 왼쪽 연결선 선택에서 켤 수 있습니다. P26의 ‘내 첫 논문’ 자동 강조·개념 분류선·첫 화면 분석 카드는 껐으며, 문헌 자체와 기존 연구 위치 자료는 유지합니다. 새 개인 논문의 배치 기능도 유지됩니다.

P22–P23 및 P39–P41 비교 후보는 이번에 원문을 충분히 재확인하지 못해 목록에서 보류했습니다. 신규 비교의 일부 근거는 기존에 확보한 IEEE 본문, 기관·저자 공개 원문, 미러 본문과 검색 색인입니다. 그래프 픽셀·초록·색인만 확인한 범위를 각 출처에서 구별합니다.

점선과 물음표는 검증할 연결입니다. 연구가 전 세계에 없다는 판정, 인용 부재의 증명, 확인된 모순을 뜻하지 않습니다. 원문으로 검증된 상충은 현재 0건이며, 새로운 DOI를 추가했다고 자동으로 대립 관계를 만들지 않습니다.

## 데이터와 원문

- 논문별 제목·저자·연도·학회/저널·DOI, 요약, 비교 조건, 원문 근거 위치를 저장합니다.
- DOI 버튼은 출판사 논문 페이지를 새 탭에서 엽니다. 본문 열람은 해당 사이트의 공개 여부와 개인/기관 구독 권한에 따릅니다.
- 출판 PDF, 사용자가 제공한 PDF, 원문 추출 전문은 저장소에 포함하지 않습니다.
- 생성형 AI·전이학습·물리 기반 학습·최적화 등 방법론 이웃에는 NAND 외 소자 논문도 포함합니다.
- 한 논문에 여러 주제 태그를 연결합니다. 방법론의 공통점과 실제 참고문헌 인용을 구별합니다.
- 원문이 확인되지 않은 관계를 DOI나 제목만으로 자동 생성하지 않습니다.
- 북마크와 개인 논문은 해당 브라우저에 저장합니다. 계정 간 동기화는 없습니다.

## 확장과 배포

`dist/`의 정적 사이트를 GitHub Pages에 공개 배포합니다. 사이트 열람에는 GPT 또는 GitHub 로그인이 필요하지 않습니다.
서지·요약·연구 위치 분석과 코드는 공개되어 있습니다.
main 브랜치 수정 → 자동 검증 → 배포 순서로 같은 주소가 업데이트됩니다. 로컬 파일만 수정한 상태에서는 웹에 반영되지 않습니다.
배포 결과는 저장소의 Actions 탭에서 확인할 수 있습니다.

소자 축과 방법론 축을 여러 태그로 연결하는 방식으로 다른 메모리·트랜지스터 분야까지 확장할 수 있습니다.
NAND를 중심으로 수집한 문헌을 별도의 소자 분야 축과 공통 방법론 축으로 탐색합니다.

PDF 텍스트 추출은 Apache-2.0 라이선스의 Mozilla PDF.js 6.5.438을 사용합니다. 배포 파일과 라이선스는 `dist/vendor/pdfjs/`에 있습니다.

## 공개 문헌 묶음

`dist/public-library-data.js`에는 공개 반영을 요청받은 156편의 서지·주제 분류와 검토 요약, 17개 직접 인용, 17개 접근·조건 비교, 12개 검증할 질문이 포함됩니다. PDF·추출 전문·저자 초록 전문·개인 메모·로컬 경로는 포함하지 않습니다. DOI가 없는 문헌도 안정된 ID로 중복을 방지합니다. 기존 개인 보관본과 메모는 브라우저에 남지만 같은 문헌·연결·질문을 맵에 중복 표시하지 않습니다. 공개 묶음의 작성 논문 표시는 추가하지 않으며, 기존 P26만 작성 논문입니다.

새 브라우저에서도 가져오기 없이 200편과 공개 원문 검토를 볼 수 있습니다. 이후 DOI·PDF로 추가하는 문헌은 계속 개인 맵에 저장되며 자동 공개되지 않습니다.

## 다른 저널·학회로 확장 (2026-11-17)

`dist/expansion-data.js`에 원문을 검토한 12편(NAND 6편 + 공통 방법론 6편)을 추가했습니다. **새로 찾은 문헌 12편** 버튼에서 이번 묶음과 연결 질문을 바로 볼 수 있습니다.

- NAND: Solid-State Electronics, JEDS, Journal of Computational Electronics, IRPS, POMACS, HPCA.
- 공통 방법론: Scientific Reports, Micromachines, ICML, ICLR, npj Computational Materials, Nature Communications.
- 새 직접 인용 16개, 접근·조건 비교 11개, 검증 질문 9개(논문 쌍 12개). 확인된 모순은 추가하지 않았습니다.
- 11편은 출판사·저자 공개 PDF, 1편은 공식 OA 전체 XML와 그림을 검토했습니다. Nature Communications 정정문도 반영했습니다. 판본과 확인 범위는 개별 카드에 표시합니다.

두 일반 ML 방법론 논문은 NAND에서 검증된 결과로 분류하지 않습니다. npj 논문과 기존 EDTM 요약은 같은 연구 계열이며 독립 재현으로 세지 않습니다. P26의 기존 동결 레이어 비교를 반영해 후속 질문은 새로운 구조군·데이터 수에서 선택 규칙을 검증하는 것으로 정리했습니다.

추가 공개 검토는 기존 13편과 새 12편을 합한 25편입니다. 기존 원문 미검토 143편의 상태는 그대로 표시합니다. 원문 PDF·전체 텍스트·개인 메모·로컬 경로는 공개 묶음에 없습니다.
